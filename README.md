# keerthanan19.github.io — personal portfolio website

## Publish on GitHub Pages (5 minutes, free)
1. Log in to GitHub as **keerthanan19**.
2. Create a new **public** repository named exactly: `keerthanan19.github.io`
3. Click **Add file → Upload files**, drag in: `index.html`, `photo.jpg`, `resume.pdf`, `portfolio.pdf`, `README.md` → **Commit changes**.
4. Go to **Settings → Pages**. Under "Build and deployment", Source = **Deploy from a branch**, Branch = **main** / **(root)** → Save.
5. Wait 1–2 minutes, then open **https://keerthanan19.github.io**

## Update later
Edit `index.html` on GitHub (pencil icon) or upload a new version — the site updates automatically.
- Add your Upwork link: remove the `<!--` and `-->` around the Upwork line in the Contact section and paste your link.
- Replace `resume.pdf` / `portfolio.pdf` when you update them (keep the same file names).

## Custom domain (optional, later)
Buy a domain (e.g. from Namecheap/Cloudflare), then Settings → Pages → Custom domain, and add the DNS records GitHub shows. Tick **Enforce HTTPS**.
